What is it:
 Region: This is a specific location from where users can access to AWS, every region has 3 (rarely 2) or more AZs and multiple Edge Locations.
 AZ: Every Availability Zone has at least two data centers separated about 100 km each one to ensure that if one fails for every possible reason the other one can maintain the workloads.
 Edge Locations: This locations are the nearest locations to an end user, so with this users can get very low latency on a lot of different services.
