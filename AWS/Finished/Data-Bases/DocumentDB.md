Key Words:
Fully managed, JSON-like, DynamoDB compatibility

What is it:
This service provides a semi-structured database, witch is compatible with mongoDB, and it work with JSON-like  documents and dynamic schemas. You can modify data as you need without worrying about manage the DB, it auto scale, make continuous backups and have enterprise grade security features.
Designed for enterprise MongoDB workloads that need full AWS integration and native durability. 

Use Cases:
Content management systems, inventory and catalog management and user profile and personalization systems.
