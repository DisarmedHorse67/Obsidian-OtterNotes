Key Words:
Basic, Developer, Business, Enterprise.

What is it:
Those are the different support plans that AWS have, one for every type of user/organization.
 * Basic: Free, 24/7 customer support, access to 7 core trusted advisor checks.
 * Developer: business hours access via email, < 12 hour response for system impairment.
 * Business: 24/7 phone/web chat access, < 1 hour for production system down, access to all trusted advisor checks.
   Enterprise (on-ramp too): 24/7 access, <15 minute response for business-critical system down, assigned a Technical Account Manager (TAM), concierge support.

Use Cases:
It depends on the business type and needs.
