What is it:
This is an specific strategy that consists on 6 different terms:
* Rehost: Move apps without changing anything.
* Replatform: Moving the app to the cloud and making little adjustments to improve its performance.
* Refactor: Rebuild the entire application to adapt it to cloud environment.
* Repurchase: Change the actual software or license to a Cloud SaaS.
* Retire: Identify apps, servers or DBs that nobody uses anymore.
* Retain: Keep the application as it is.
