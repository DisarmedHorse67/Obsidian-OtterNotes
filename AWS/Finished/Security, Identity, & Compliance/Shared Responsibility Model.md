Key Words:
AWS and User responibillity.

What is it:
This is not a service, this is a model of how AWS manages different service:
* For unmanaged services, AWS just have the responsibility to ensure physical security to the servers, the rest is responsibility of the user.
* For managed services AWS manages also network security, O.S. patching and more, so you just have to ensure the security of who access to your instances, buckets or other managed services.
* For fully managed services, AWS manage almos everything, you just need to manage your information security but you have the option to move some parameters of the network or things instance related.
* Finally, serverless services means that AWS is going to manage everything from physical security, to networks, elasticity and scalability, you just worry about your information security
