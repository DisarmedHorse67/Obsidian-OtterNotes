Key Words:
One bill-multiple accounts, Manage multiple accounts and groups

What is it:
This service provides an easy way to manage multiple accounts from a single console, from here you can manage single accounts or create groups to manage multiple accounts. You can manage politics, access, and more security features. Also you can have a single bill that join all the accounts under management to a single main account.  

Use Cases:
Whenever you need to manage multiple accounts.
