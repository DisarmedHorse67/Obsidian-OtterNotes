Key Words:
Load Distribution, Health Checks, HA, AutoScaling

What is it:
This service ir a Load Balancer, its main function is to spread user demand of compute or network services. It can auto scale to maintain a correct workflow with EC2 auto scaling or other services like so. 

Use Cases:
Apps with more than one backend server.
Spread incoming traffic evenly across EC2 instances, containers or ip addresses in different AZs
