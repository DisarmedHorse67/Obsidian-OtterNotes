Key Words:
Fully managed, code deployment, PaaS

What is it:
It us used to deploy your own code to create web pages and apps without the need, you simply upload your code and the rest is managed by AWS (Load Balancing, Elasticity, infrastructure).
You have the option of tuning your AWS resources (EC2, Auto Scaling, etc.) if needed.

Use Cases:
Developers that does not want to manage servers.
