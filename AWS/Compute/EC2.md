Key words:
Cloud Computing, Virtual Servers (Instances), Unmanaged service

What is it:
It is a IAAS, with this service you can create machines and manage every part of them, it has a lot of types for whatever use case that you will need, such as:
General Purpose, compute , memory , storage optimized and Accelerated Computing(GPU/Custom ML chips).
It cost depends in how much time you use it and what type of instance are you using.

Use cases:
Web Apps and backend.
