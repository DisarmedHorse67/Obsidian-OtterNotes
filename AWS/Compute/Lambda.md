Key Words:
Serverless, Billing by millisecond and requests, Trigger functions 

What is it:
It is a service that lets you use functions, triggered by an event and that requires a small amount of time to run, it is serverless so you can focus in your function and let the management of the environment to AWS.
You have a Max execute time of 15 minutes per function.

Use Cases:
light API calls, short functions and event processing
